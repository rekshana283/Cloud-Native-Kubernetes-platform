# Cloud Native Kubernetes Platform

A hands-on Kubernetes project focused on deploying, managing, monitoring, troubleshooting, and scaling containerized applications using Docker, Kubernetes, and Minikube.

The project demonstrates practical Kubernetes operations including deployments, services, scaling, self-healing, configuration management, health checks, ingress, logging, troubleshooting, rollout management, rollback, resource monitoring, HPA, namespaces, and Kubernetes Dashboard.

---

## Project Overview

This project was built as a practical learning environment to understand how Kubernetes manages containerized applications.

The application used throughout the project is NGINX, deployed and managed locally using Minikube.

The project covers both fundamental and advanced Kubernetes operations in a local, zero-cost environment.

---

## Technologies Used

- Docker
- Kubernetes
- Minikube
- kubectl
- NGINX
- Kubernetes Metrics Server
- Horizontal Pod Autoscaler (HPA)
- Kubernetes Dashboard
- Windows
- Command Prompt / PowerShell

---

## Project Architecture

The project runs Kubernetes locally through Minikube.

Application flow:

Docker
↓
Minikube
↓
Kubernetes Cluster
↓
NGINX Deployment
↓
Pods
↓
Kubernetes Service
↓
Monitoring and Auto Scaling

Additional Kubernetes components were used for configuration, health monitoring, traffic management, troubleshooting, and workload management.
