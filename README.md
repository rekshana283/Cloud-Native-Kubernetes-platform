# Cloud Native Kubernetes Platform

A hands-on Cloud & DevOps project focused on deploying, managing, scaling, monitoring, and troubleshooting containerized applications using Docker and Kubernetes.

## Project Overview

This project demonstrates a practical Kubernetes workflow starting from a local Kubernetes environment and progressing toward cloud-based deployment on AWS.

The project currently covers:

- Docker container fundamentals
- Kubernetes cluster setup using Minikube
- NGINX application deployment
- Kubernetes Services and NodePort
- Pod scaling and self-healing
- Rolling updates and rollbacks
- ConfigMaps and Secrets
- Resource requests and limits
- Liveness and readiness probes
- Ingress
- Application logs
- Kubernetes troubleshooting and recovery

### Planned Cloud & DevOps Expansion

- Containerize a custom application
- Push container images to Amazon ECR
- Deploy the application on Amazon EKS
- Implement CI/CD with GitHub Actions
- Perform cloud-based Kubernetes operations and troubleshooting
